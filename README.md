# 晶格 · Kittel 固体物理学习网站

依据用户提供的 Kittel *Introduction to Solid State Physics*（8th ed.），提供第 1–22 章中文课程、渐进推导、定量交互实验和原书编号公式索引。

## 内容与覆盖边界

- 第 1–5 章保留已有主题单元和实验；第三章进一步补充晶格计数、Born–Mayer 平衡、弹性稳定性、Christoffel 方程与声速反演的推理和算例。
- 第 6 章新增自由电子气课程及费米球、粒子数守恒的费米分布、输运和霍尔实验。
- 第 7–22 章每章提供四个核心主题、渐进推导、两个定量实验、概念检查和带解答练习。实验明示变量单位、近似条件和模型边界，不把示意曲线当成实际材料数据。
- 全书编号公式索引包含 1026 个数学展示，支持按章节、原式号和页码查找。公式以透明图像保留原始数学字形，避免旧 PDF 字体映射造成上下标丢失。
- 编号公式索引不是逐式详解：核心公式的推导在课程中展开，未编号的行内公式和中间计算没有单独做完备索引。不能将本版本宣称为全书每个公式都有完整推导。
- 中文讲解为重新编写；不发布用户的源 PDF、教材正文扫描页或原书插图。公式索引保留页码用于核对，原书 SI/CGS 表达式必须先统一单位制再和实验比较。

## 视觉与交互

背景按用户提供的黑洞点云图片重绘为程序化动画：密集尘埃、横向吸积盘、上方弯曲光环与中央暗核。整体倾斜约 20°，暗核半径在电脑端约为视口宽度 8.2%，手机端约 13.5%，另按视口高度限制。暗色为暖银点云，浅色为墨蓝点云与淡色核心留白。普通玻璃表面基础填色约 5%，顶栏、小控件和公式推导约 2%；文字保持不透明。填色比例不等于模糊、反射合成后的最终像素透明度。

WebGL2 用圆角距离场计算边缘法线，采样背景画布完成折射、边缘散射和轻微色散；原生 backdrop-filter 对模块下面的实际 DOM 内容进行模糊。WebGL 并未截图或折射任意 DOM，也不是原生 iOS 的光学实现。无 WebGL2 时退化为透明毛玻璃，减少动态效果设置会停止背景动画。

阅读或实验单元采用一层主要光学表面；其内的公式、按钮、来源说明不会再重复模糊和投影。正文透镜区为手机约 16 CSS px、桌面约 22 CSS px，小控件约 11 CSS px，并限制在短边的 22% 内；内部不绘制额外光学遮罩。偏移图案处的光学响应强于平坦区域，避免整圈描白边。滚动事件立即更新几何，滚动期间逐帧跟随，不隐藏折射或等待停稳；背景纹理仅在壁纸帧更新时上传。固定目录与顶部栏的光学优先级高于正文。

章节切换使用同页路由，支持浏览器前进/后退；总目录打开时预加载课程模块，准备完成后才提交切换，不以加载页替换当前课程。切章复用同一背景和玻璃画布，轨道时间连续；View Transition 仅淡入淡出正文与导航，不冻结整屏背景。切换请求可中断，减少动态效果时直接切换。手机目录保持正文亮度，主题、学习进度保存在本地。KaTeX 和字体随网站打包，不依赖外部公式 CDN。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
npm run build
npm run preview
```

项目路径前缀为 /Solid-state-learning/，按终端地址访问。生产文件在 dist/。

## 验证

```sh
npx playwright install chromium
npm test
```

覆盖桌面和手机的课程访问、章节同页切换、公式渲染、互动参数、关键解析值/极限、玻璃上下文、目录安全间距和横向溢出。

scripts/extract_formula_atlas.py 根据本地源 PDF 重建公式索引；需要 pdfplumber、pypdfium2 和 Pillow。用 --help 查看参数，源文件不在仓库中。

scripts/audit-independent-sites.mjs 用于核查独立静态站点。通过 SITE_REPO 指定仓库路径、SITE_URL 指定本地服务地址、CHROME_PATH 指定浏览器；只输出本地审计报告。

## 发布

main 分支推送后由 GitHub Actions 构建并发布到 https://tinsense.github.io/Solid-state-learning/ 。

学习站、个人主页和独立工具共用 src/lib/glassEngine.ts、src/lib/latticeWallpaper.ts 和 src/styles/shared-material.css。设置 SITE_REPO 为 Tinsense.github.io 本地仓库路径后，运行 node scripts/build-shared-sites.mjs 生成该站的 js/site-glass.js 与 css/site-glass.css，再提交两个仓库。不要单独编辑生成文件。scripts/check-material-parity.mjs 对照两站的着色器源码、透明度、模糊和圆角，并保存明暗主题截图。

跨章节入口在左上角“总目录”，打开后玻璃面板从左向右滑出，支持全部 22 章、方向键、Home/End 与 Escape；侧栏只列本章内容。抽屉动画期间光学遮罩逐帧同步，减少动态效果时直接切换。

顶部导航为透明布局容器，目录、品牌、搜索、主题与进度各自采用独立的透明胶囊玻璃。手机保留目录、品牌及圆形主题按钮；底部章节目录和正文快捷按钮使用相同的圆弧。正文内的小按钮只增加局部折射边缘，不重复叠加 backdrop 模糊。圆角透镜将页面向下的坐标转换为纹理向上的坐标，并统一处理 RGB 与透明度的抗锯齿覆盖，避免圆角采样反向和发亮接缝。

共享壁纸不依赖外部图片。吸积盘是偏心投影，左侧粒子带更长、更宽、更亮，右侧更短、更薄、更暗，叠加连续的小幅起伏而非对称椭圆环。吸积盘与光环采用持久化粒子相位，角速度随半径增大而降低；尘埃纹理缓存后围绕同一中心慢转，不逐帧随机闪烁。手机与电脑分别控制粒子数，后台标签页暂停，减少动态效果时冻结。此为用户指定的黑洞主题视觉插画，不是广义相对论光线追踪，也不作为固体物理实验数据或晶体结构图。

高光随背景取样的亮度和色彩变化，主要集中于约 45° 入射方向的圆角，而非沿整侧描线；正文圆角为桌面 44px、手机 36px，按钮为完整胶囊圆角。加宽透镜区使用连续的位移衰减，但不改变边缘与中央的模糊程度：着色器读取实际 CSS blur/saturate/brightness，先对背景进行多点滤波，再采样位移后的场景。背景更新时生成 mipmap，避免宽模糊采样出现重复的清晰纹理。嵌套按钮继承外层材质的模糊参数。参照用户提供的透明玻璃控件截图，并非原生系统材质的像素级复制。WebGL 对壁纸取样折射，DOM 后方内容由 backdrop-filter 散射；这不是对任意网页元素进行光线追踪。

光学设计参考 Liquid Glass Studio（MIT）：https://github.com/iyinchao/liquid-glass-studio 。按其许可保留项目内已有版权声明；本站实现针对长文阅读和移动设备做了性能、对比度和动画限制。
